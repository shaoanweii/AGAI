# 洞察引擎 UI 设计规范

## 1. UI 定位

洞察引擎是企业级 VOC 数据智能治理后台，UI 应呈现专业、克制、清晰、高效的后台系统气质。

设计目标：

- 适合长时间办公使用。
- 支持高密度数据展示。
- 强化筛选、列表、状态、异常、审核、监控等工作流。
- 避免营销化、装饰化、过度视觉化。
- 保持多模块、多页面的一致性。

关键词：

```text
专业 / 清晰 / 克制 / 高效 / 可读 / 可追踪 / 稳定
```

## 2. 设计基调

### 2.1 视觉风格

- 后台管理系统风格。
- 白色内容区 + 浅蓝灰页面背景。
- 蓝色作为主操作和选中状态。
- 灰色体系承载边框、表头、辅助信息。
- 状态色只用于状态、风险、反馈，不做大面积装饰。

### 2.2 页面观感

推荐：

- 清晰的左侧导航。
- 稳定的顶部标题区。
- 紧凑但不拥挤的筛选区。
- 高可读表格。
- 明确的操作按钮。
- 清晰的状态标签。

避免：

- 大面积渐变背景。
- 装饰性插画。
- 过大圆角。
- 高饱和色块堆叠。
- 卡片嵌套卡片。
- 过多阴影。

## 3. 色彩规范

### 3.1 主色

| 名称 | 色值 | 使用场景 |
|---|---|---|
| 主色 Blue | `#1677FF` | 主按钮、链接、菜单选中、页签选中、重点数字 |
| 品牌深蓝 | `#0B457F` | Logo 文字、品牌强调、重要标题辅助 |
| 主色浅蓝 | `#EAF3FF` | 菜单选中背景、浅色提示背景、页面背景局部 |

### 3.2 中性色

| 名称 | 色值 | 使用场景 |
|---|---|---|
| 黑色 | `#000000` | 极少使用 |
| 标题文字 | `#1F2733` | 页面标题、表头、重要正文 |
| 正文文字 | `#4E5969` | 默认正文 |
| 次级文字 | `#5F6A7A` | 菜单文字、说明文字 |
| 辅助文字 | `#929AA6` | 占位说明、图标默认色 |
| 占位文字 | `#C9CED6` | Input placeholder |
| 深边框 | `#DFE2E8` | Header 分割线、模块边框 |
| 常规边框 | `#EBEDF0` | 表格线、输入框边框 |
| 表头背景 | `#F5F7FA` | 表格表头、浅底区 |
| 页面背景 | `#EAF3FF` | 页面整体背景 |
| 白色 | `#FFFFFF` | 内容卡片、表格、侧边栏 |

### 3.3 功能色

| 类型 | 色值 | 使用场景 |
|---|---|---|
| 成功 | `#14CA64` | 启用、成功、通过、正常 |
| 警告 | `#FAB007` | 预警、待处理、低置信、部分失败 |
| 错误 | `#FF5959` | 失败、异常、驳回、删除 |
| 信息 | `#1677FF` | 处理中、提示、系统信息 |

### 3.4 使用规则

- 页面主色只用于核心操作和选中状态。
- 同一页面主按钮不宜超过 1 个。
- 状态色不用于普通装饰。
- 红色只用于错误、危险、删除、驳回。
- 监控图表可以使用扩展色板，但不要破坏整体蓝灰基调。

## 4. 字体规范

### 4.1 字体族

```css
font-family: "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif;
```

### 4.2 字号

| 层级 | 字号 | 行高 | 字重 | 使用场景 |
|---|---:|---:|---:|---|
| 页面主标题 | 20px | 28px | 600 | 顶部标题、重要页面名 |
| 模块标题 | 16px | 24px | 600 | 卡片标题、表格标题、弹窗标题 |
| 强调正文 | 14px | 22px | 500/600 | 表头、关键字段、操作文本 |
| 默认正文 | 14px | 22px | 400 | 表格内容、表单文本 |
| 辅助文字 | 12px | 20px | 400 | 状态补充、字段说明、图表注释 |
| 数字指标 | 24px | 32px | 600 | 主控台/监控指标卡 |

### 4.3 字体使用规则

- 后台系统正文统一 14px。
- 不使用小于 12px 的文字。
- 表格正文默认 14px。
- 页面内不要使用超大标题。
- 数字指标可适度放大，但不超过 32px。

## 5. 间距规范

### 5.1 页面间距

| 场景 | 间距 |
|---|---:|
| 主内容区 padding | 24px |
| 页面模块间距 | 16px / 24px |
| 卡片内边距 | 16px / 24px |
| 表格与分页间距 | 16px |
| 查询区与表格间距 | 16px |
| 表单项纵向间距 | 16px |
| 按钮间距 | 8px |

### 5.2 栅格规则

- 基础间距单位建议为 4px。
- 常用间距：4、8、12、16、20、24、32。
- 页面整体以 24px 为主。
- 组件内部以 8px、12px、16px 为主。

## 6. 圆角与阴影

### 6.1 圆角

| 场景 | 圆角 |
|---|---:|
| 按钮 | 4px |
| 输入框 | 4px |
| 表格容器 | 4px |
| 内容卡片 | 4px |
| 状态标签 | 2px / 4px |
| 弹窗 | 6px |
| 头像 | 50% |

### 6.2 阴影

原则：

- 页面模块默认不用阴影。
- 弹窗、下拉、Tooltip 可使用轻阴影。
- 避免重阴影和悬浮卡片堆叠。

推荐阴影：

```css
box-shadow: 0 4px 16px rgba(31, 39, 51, 0.08);
```

### 7.1 系统框架

推荐布局：

```text

顶部 Header 84px
主内容区 24px padding
```

### 7.2 左侧导航

| 项目 | 规范 |
|---|---|
| 宽度 | 260px - 280px |
| 背景 | `#FFFFFF` |
| Logo 区高度 | 84px |
| 菜单图标 | 24px |
| 菜单文字 | 16px / 600 |
| 默认文字色 | `#5F6A7A` |
| 默认图标色 | `#929AA6` |
| 选中背景 | `#EAF3FF` |
| 选中文字 | `#1677FF` |

### 7.3 顶部 Header

| 项目 | 规范 |
|---|---|
| 高度 | 84px |
| 背景 | `#FFFFFF` |
| 下边框 | `1px solid #D0D9E4` |
| 左侧 | 页面标题或页签 |
| 右侧 | 用户信息、退出登录 |

### 7.4 主内容区

| 项目 | 规范 |
|---|---|
| 背景 | `#EAF3FF` 或 `#F5F7FA` |
| 内边距 | 24px |
| 内容区背景 | `#FFFFFF` |
| 最小宽度 | 1280px |

## 9. 导航与页签规范

### 9.1 菜单规范

- 一级菜单展示图标 + 文案。
- 二级菜单只展示文案。
- 菜单选中态必须明显。
- 菜单顺序固定，不随用户习惯动态改变。
- 无权限菜单不展示。

### 9.2 页签规范

适用于同一页面内的业务视图切换。

示例：

- 结果数据 / 原始数据
- 文本新词 / 问卷新词
- 前置规则 / 后置规则
- 车系管理 / 品牌管理 / 车企管理

页签样式：

- 激活：`#1677FF`，600。
- 未激活：`#5F6A7A`。
- 页签间距：24px。
- 不建议超过 5 个页签。

## 10. 按钮规范

### 10.1 按钮类型

| 类型 | 使用场景 |
|---|---|
| 主按钮 | 查询、新增、保存、确认、发布 |
| 默认按钮 | 重置、取消、返回 |
| 文本按钮 | 表格操作，如详情、编辑、复制 |
| 危险按钮 | 删除、驳回、停用 |

### 10.2 按钮顺序

弹窗底部：

```text
取消   确定
```

批量操作：

```text
新增 / 导入 / 导出 / 批量启用 / 批量禁用
```

表格操作：

```text
详情 / 编辑 / 更多
```

### 10.3 按钮尺寸

| 场景 | 高度 |
|---|---:|
| 默认按钮 | 32px |
| 紧凑按钮 | 28px |
| 表格文本按钮 | 22px 行高 |

## 11. 表格规范

### 11.1 表格样式

| 项目 | 规范 |
|---|---|
| 表头背景 | `#F5F7FA` |
| 表头文字 | `#1F2733` / 600 |
| 正文文字 | `#1F2733` / 400 或 500 |
| 行高 | 48px - 56px |
| 边框 | `#EBEDF0` |
| Hover 背景 | `#F5F7FA` |

### 11.2 表格列顺序

推荐顺序：

```text
选择框
序号
核心名称/ID
客户/项目
业务字段
状态
统计指标
创建/更新信息
操作
```

### 11.3 操作列

- 固定在右侧。
- 常规展示 2-3 个操作。
- 超过 3 个放入“更多”。
- 删除、停用、驳回等危险操作使用红色。

### 11.4 空表格

空态居中展示：

```text
暂无数据
```

如用户有新增权限，可展示：

```text
暂无数据，立即新增
```

## 12. 表单规范

### 12.1 查询表单

布局：

- 单行优先。
- 多条件使用展开/收起。
- 标签右对齐。
- 输入控件宽度统一。

常用控件宽度：

| 控件 | 宽度 |
|---|---:|
| 普通输入框 | 200px |
| 下拉选择 | 200px |
| 日期范围 | 280px - 320px |
| 级联选择 | 240px |
| 多选选择 | 240px |

### 12.2 编辑表单

字段分组：

```text
基础信息
适用范围
配置内容
执行策略
异常策略
备注
```

### 12.3 表单校验

校验提示：

- 显示在字段下方。
- 文案明确。
- 不使用技术错误码。

示例：

```text
请输入规则名称
规则编码已存在
请选择适用客户
```

## 13. 弹窗与抽屉规范

### 13.1 弹窗

适用：

- 简单新增
- 简单编辑
- 确认操作
- 小型详情

宽度：

| 类型 | 宽度 |
|---|---:|
| 小弹窗 | 480px |
| 中弹窗 | 640px |
| 大弹窗 | 800px |

### 13.2 抽屉

适用：

- 数据详情
- 审核详情
- 规则详情
- 处理链路
- 长表单编辑

宽度：

| 类型 | 宽度 |
|---|---:|
| 中抽屉 | 640px |
| 大抽屉 | 800px - 960px |
| 复杂详情 | 70% 屏宽 |

### 13.3 二次确认

以下操作必须二次确认：

- 删除
- 批量删除
- 停用
- 发布
- 回滚
- 驳回
- 重跑
- 导出敏感数据

确认文案格式：

```text
确定要删除该规则吗？删除后不可恢复。
确定要停用该流程吗？停用后相关任务将不再执行。
```

## 14. 状态标签规范

### 14.1 通用状态

| 状态 | 样式 |
|---|---|
| 启用 | 绿色浅底 + 绿色文字 |
| 禁用 | 灰色浅底 + 灰色文字 |
| 成功 | 绿色浅底 + 绿色文字 |
| 失败 | 红色浅底 + 红色文字 |
| 处理中 | 蓝色浅底 + 蓝色文字 |
| 待审核 | 橙色浅底 + 橙色文字 |
| 驳回 | 红色浅底 + 红色文字 |
| 预警 | 橙色浅底 + 橙色文字 |
| 异常 | 红色浅底 + 红色文字 |

### 14.2 置信度状态

| 等级 | 样式 |
|---|---|
| 高置信 | 绿色 |
| 中置信 | 蓝色或橙色 |
| 低置信 | 橙色 |
| 不可信 | 红色 |

| 场景 | 图表 |

## 16. 图标规范

### 16.1 使用原则

- 菜单图标使用线性或面性统一风格。
- 操作按钮优先使用文字，必要时加图标。
- 图标不单独表达复杂含义。
- 不使用多套风格混杂图标。

### 16.2 尺寸

| 场景 | 尺寸 |
|---|---:|
| 菜单图标 | 24px |
| 按钮图标 | 16px |
| 表格操作图标 | 16px |
| 空态图标 | 64px - 120px |

## 17. 处理链路 UI 规范

### 17.1 链路展示

处理链路推荐使用时间线或横向步骤条。

节点状态：

- 未开始
- 处理中
- 成功
- 失败
- 跳过
- 转人工

### 17.2 节点卡片

节点详情展示：

- 节点名称
- 节点类型
- 执行状态
- 开始时间
- 结束时间
- 耗时
- 输入摘要
- 输出摘要
- 异常原因

## 18. 审核对比 UI 规范

### 18.1 对比结构

审核详情中建议采用三栏或上下对比：

```text
原始数据
系统结果
人工修正结果
```

### 18.2 差异高亮

- 新增内容：绿色。
- 删除内容：红色。
- 修改内容：橙色。
- 未变化内容：默认文字色。

### 18.3 审核操作区

固定在详情底部：

```text
驳回   修改通过   通过
```

## 19. 监控 UI 规范

### 19.1 指标卡

指标卡内容：

- 指标名称
- 当前值
- 环比/同比
- 状态
- 小趋势，选填

### 19.2 异常列表

异常列表重点展示：

- 异常类型
- 影响对象
- 当前值
- 阈值
- 触发时间
- 处理状态
- 操作

### 19.3 告警等级

| 等级 | 视觉 |
|---|---|
| 严重 | 红色标签 |
| 高 | 红色或深橙 |
| 中 | 橙色 |
| 低 | 蓝色或灰色 |

## 20. 响应式与分辨率

### 20.1 支持范围

洞察引擎以桌面端为主。

推荐支持：

- 1280px 及以上可正常使用。
- 1440px 为主要设计基准。
- 1920px 保持内容宽度和可读性。

### 20.2 横向滚动

字段较多的表格允许横向滚动。

固定列建议：

- 左侧选择框/核心 ID。
- 右侧操作列。

## 21. 可访问性与可读性

- 文字和背景对比度要清晰。
- 状态不能只靠颜色表达。
- 表格重要字段不应被截断。
- 超长文本使用 Tooltip 或详情抽屉。
- 所有图标按钮需要 hover 提示。

## 22. UI 验收标准

### 22.1 一致性

- 同类页面布局一致。
- 同类按钮样式一致。
- 同类状态颜色一致。
- 同类表单校验一致。

### 22.2 可读性

- 表格字段不拥挤。
- 重要字段可直接扫描。
- 筛选条件有清晰分组。
- 监控指标有明确单位。

### 22.3 可操作性

- 核心操作入口明确。
- 危险操作有确认。
- 异常状态有处理入口。
- 审核页面能清楚对比差异。

### 22.4 产品化

- 客户/项目切换后 UI 表现一致。
- 不出现项目定制化视觉风格。
- 配置、规则、知识、监控页面保持同一套交互和视觉语言。
