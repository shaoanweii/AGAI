# 洞察引擎产品化 PRD

## 1. 文档说明

### 1.1 文档目标

本文档用于指导洞察引擎从项目交付型系统升级为标准化、可配置、可复用、可运营的产品化平台。文档按照已确认的产品架构清单展开，覆盖每个一级菜单和二级菜单的页面内容、功能操作、异常处理、权限要求和验收标准，可直接作为产品、研发、测试、UI、交付团队的需求依据。

### 1.2 产品定位

洞察引擎是面向多客户、多项目、多渠道 VOC 场景的数据智能治理平台，提供从数据接入、字段标准化、处理流水线、规则/模型协同、模型后处理、知识管理、审核反馈、质量监控到系统配置的全链路产品能力。

### 1.3 建设目标

1. 将项目定制逻辑沉淀为客户、项目、渠道、规则、模型、流程等配置。
2. 建立标准化 VOC 数据资产体系，区分原始数据、结果数据和异常数据。
3. 建立可配置的数据处理流水线，支持规则、模型、后处理、审核等节点协同。
4. 建立模型后处理能力，保障模型输出可结构化、可校验、可解释、可入库。
5. 建立知识中心作为标签、观点、关键词、场景、品牌车系等业务资产库。
6. 建立审核反馈闭环，将人工纠错、新词处理、低置信审核沉淀为反馈样本。
7. 建立数据质量、处理链路、标签质量、模型质量、后处理质量等监控能力。
8. 建立多客户、多项目、多角色、多数据范围的权限体系。

### 1.4 角色定义

| 角色 | 说明 | 主要权限 |
|---|---|---|
| 超级管理员 | 平台最高权限用户 | 全部菜单、全部客户/项目、全部配置、权限管理 |
| 系统管理员 | 负责平台基础配置 | 客户、项目、账号、角色、权限、模型配置、审计 |
| 数据接入管理员 | 负责数据源和接入任务 | 数据源、字段映射、接入任务、接入记录 |
| 数据治理人员 | 负责数据资产和异常数据治理 | 原始数据、结果数据、异常数据、数据质量监控 |
| 业务运营人员 | 负责标签、观点、规则、审核处理 | 知识中心、规则中心、审核反馈 |
| 算法/模型运营人员 | 负责模型和后处理质量 | 模型配置、后处理配置、模型质量监控、后处理质量监控 |
| 审核人员 | 负责人工审核 | 纠错审核、AI低置信审核、新词处理、未归一观点 |
| 只读用户 | 查看授权数据 | 查询、查看详情，无新增、编辑、删除、导出权限 |

### 1.5 通用权限原则

1. 所有数据类页面必须受客户、项目、渠道、品牌车系、标签等数据权限控制。
2. 所有操作按钮必须受按钮权限控制。
3. 无菜单权限时不展示对应菜单。
4. 无按钮权限时不展示对应操作，特殊场景可置灰并提示“无操作权限”。
5. 导出、重跑、发布、回滚、删除、批量操作、审核通过/驳回属于高风险操作，必须单独授权。

## 2. 通用产品规范

### 2.1 通用页面结构

列表类页面统一采用：

```text
页面标题/页签
筛选区
操作区
数据表格
分页
详情抽屉/新增编辑弹窗
```

监控类页面统一采用：

```text
全局筛选区
指标卡
趋势图/分布图
异常明细列表
详情抽屉
```

审核类页面统一采用：

```text
筛选区
审核列表
审核详情
结果对比
审核操作区
```

### 2.2 通用操作

| 操作 | 说明 |
|---|---|
| 查询 | 按筛选条件刷新列表 |
| 重置 | 清空筛选条件，保留默认客户/项目权限范围 |
| 新增 | 打开新增弹窗或页面 |
| 编辑 | 打开编辑弹窗或页面 |
| 详情 | 查看完整信息，不可编辑 |
| 删除 | 删除草稿或未被引用对象，需二次确认 |
| 启用 | 使配置生效 |
| 禁用 | 停止配置继续生效 |
| 复制 | 基于已有配置生成副本 |
| 导出 | 异步生成文件，进入下载管理 |
| 批量操作 | 对选中记录执行启用、禁用、删除、导出等动作 |

### 2.3 通用状态

| 状态 | 说明 |
|---|---|
| 草稿 | 已创建但未启用或未发布 |
| 启用 | 当前配置可用 |
| 禁用 | 当前配置不可用 |
| 待处理 | 任务或记录等待处理 |
| 处理中 | 系统正在处理 |
| 成功 | 处理完成且无异常 |
| 失败 | 处理失败 |
| 预警 | 存在风险但未阻断 |
| 异常 | 存在明确错误或无法继续处理 |
| 已关闭 | 异常或告警已处理完成 |

### 2.4 通用异常处理

| 异常 | 页面处理方式 |
|---|---|
| 接口请求失败 | 展示错误提示，保留当前筛选条件 |
| 查询无数据 | 展示“暂无数据”空态 |
| 保存失败 | 表单不关闭，字段级或全局展示失败原因 |
| 删除失败 | 展示引用关系或失败原因 |
| 权限不足 | 不展示操作或置灰提示 |
| 数据已被他人修改 | 提示刷新后重试 |
| 批量操作部分失败 | 展示成功/失败明细，可下载失败记录 |
| 导出失败 | 在下载管理中展示失败原因，支持重试 |

## 3. 主控台

### 3.1 经营概览

#### 页面目标

为管理者和运营人员提供当前客户/项目的整体运行概览，快速了解数据接入、处理、质量、审核、告警等核心状态。

#### 页面内容

1. 顶部全局筛选：
   - 客户
   - 项目
   - 渠道
   - 时间范围
2. 核心指标卡：
   - 原始数据量
   - 结果数据量
   - 接入成功率
   - 处理成功率
   - 标签覆盖率
   - 模型低置信占比
   - 待审核数量
   - 未关闭告警数
3. 趋势区：
   - 数据接入趋势
   - 处理成功率趋势
   - 标签覆盖率趋势
   - 告警数量趋势
4. 快捷入口：
   - 异常数据
   - 纠错审核
   - AI低置信审核
   - 告警事件

#### 功能操作

- 切换客户/项目后刷新全部指标。
- 点击指标卡跳转对应明细页面。
- 点击趋势图节点查看当日明细。
- 点击快捷入口跳转对应页面并携带筛选条件。

#### 异常处理

- 无客户权限：展示“暂无可访问客户”。
- 指标加载失败：对应指标卡展示“加载失败”，支持刷新。
- 图表无数据：展示空态。
- 部分指标异常：不影响其他模块展示。

#### 验收标准

- 指标口径和监控中心一致。
- 指标卡跳转后筛选条件自动带入。
- 不同权限用户只能看到授权客户/项目数据。

### 3.2 待办中心

#### 页面目标

统一展示用户需要处理的待办事项，提升审核、异常处理、规则/监控事件处理效率。

#### 页面内容

待办类型：

- 纠错审核
- AI低置信审核
- 新词处理
- 未归一观点
- 异常数据处理
- 告警事件处理
- 规则异常处理

#### 筛选条件

| 筛选项 | 类型 |
|---|---|
| 待办类型 | 多选 |
| 客户 | 多选 |
| 项目 | 多选 |
| 优先级 | 高/中/低 |
| 状态 | 待处理/处理中/已处理 |
| 创建时间 | 日期范围 |

#### 列表字段

| 字段 | 说明 |
|---|---|
| 待办标题 | 待办事项摘要 |
| 待办类型 | 来源模块 |
| 客户/项目 | 所属范围 |
| 优先级 | 高/中/低 |
| 来源对象 | 数据ID、告警ID、审核ID等 |
| 创建时间 | 待办生成时间 |
| 截止时间 | 如有 |
| 状态 | 待处理/处理中/已处理 |
| 操作 | 查看、处理 |

#### 功能操作

- 查看待办详情。
- 跳转来源页面处理。
- 标记处理中。
- 已处理待办自动关闭。

#### 异常处理

- 来源对象已删除：展示“来源对象不存在”，允许关闭待办。
- 待办已被他人处理：提示状态已变更并刷新。

### 3.3 趋势看板

#### 页面目标

从趋势角度观察数据接入、处理质量、标签质量、模型质量和告警变化。

#### 页面内容

图表：

- 数据量趋势
- 处理成功率趋势
- 字段完整率趋势
- 标签覆盖率趋势
- 模型低置信趋势
- 人工修改率趋势
- 告警趋势

#### 功能操作

- 支持按日、周、月切换粒度。
- 支持客户/项目/渠道筛选。
- 图表支持导出图片或数据，按权限控制。

- 导出查询结果。

## 12. 非功能需求

### 12.1 性能要求

- 普通列表查询响应时间建议不超过 3 秒。
- 大数据查询必须分页。
- 导出采用异步任务。
- 监控看板默认查询最近 7 天或 30 天，避免默认全量查询。

### 12.2 安全要求

- 敏感字段默认脱敏。
- 导出必须校验权限。
- 审核、发布、删除、回滚、重跑必须记录审计。
- 前端不得绕过后端数据权限。

### 12.3 可用性要求

- 接口失败不导致页面白屏。
- 配置被引用时给出影响范围。
- 批量操作提供失败明细。
- 异常可定位到具体数据、节点或配置。

### 12.4 可追溯要求

结果数据必须可追溯：

- 原始数据。
- 数据源。
- 字段映射。
- 处理流程。
- 规则。
- 模型。
- 后处理。
- 审核。
- 最终结果版本。

## 13. 总体验收标准

1. 所有一级菜单和二级菜单均可按权限展示。
2. 所有列表页具备筛选、列表、分页、详情和状态展示。
3. 所有配置页具备新增、编辑、启用、禁用和必要校验。
4. 所有高风险操作具备二次确认和审计记录。
5. 原始数据、结果数据、异常数据具备处理链路查看能力。
6. 后处理配置可被处理流程引用，并能在结果详情中查看执行结果。
7. 审核反馈能沉淀反馈样本。
8. 监控中心能查看核心指标、趋势和异常明细。
9. 客户、项目、渠道、角色、权限能控制数据和功能访问范围。
