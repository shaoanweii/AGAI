# 洞察引擎产品架构清单

| 一级菜单 | 二级菜单 | 功能说明 |
|---|---|---|
| 主控台 | 经营概览 | 展示当前客户/项目下的数据接入量、处理量、异常量、标签覆盖率、模型处理质量、待审核任务、告警事件等核心指标。 |
| 主控台 | 待办中心 | 汇总待处理事项，包括纠错审核、AI低置信审核、新词处理、未归一观点、数据异常、规则异常等。 |
| 主控台 | 趋势看板 | 展示数据量、处理成功率、标签覆盖率、模型低置信占比、人工修改率、告警数量等趋势。 |
| 数据资产 | 原始数据 | 查询所有接入的VOC原始声音数据，支持按客户、项目、渠道、品牌、车系、时间、关键词、数据状态筛选，查看原文、来源和接入信息。 |
| 数据资产 | 结果数据 | 查询经过清洗、规则、模型、后处理后的最终结果数据，查看标签、观点、情感、意图、关键词、置信度、处理链路和审核状态。 |
| 数据资产 | 异常数据 | 汇总接入失败、字段异常、处理失败、模型失败、后处理失败、低置信、规则冲突等异常数据，支持处理、重跑、分派和关闭。 |
| 数据接入 | 数据源管理 | 管理数据来源，包括API、文件、数据库同步、消息队列、爬虫等数据源配置，维护数据源类型、接入方式、状态和责任人。 |
| 数据接入 | 字段映射 | 配置外部数据字段到平台标准字段的映射关系，支持字段类型、必填规则、默认值、枚举映射和格式校验。 |
| 数据接入 | 接入任务 | 配置数据接入任务，包括任务名称、数据源、执行方式、调度周期、接入范围、重试策略和启停状态。 |
| 数据接入 | 接入记录 | 查看每次接入任务的执行结果，包括批次号、接入量、成功量、失败量、重复量、耗时、失败原因和重试操作。 |
| 处理流水线 | 流程配置 | 配置数据从接入到最终入库的处理流程，包括字段标准化、数据规则、模型任务、后处理、质量校验、人工审核等节点。 |
| 处理流水线 | 任务管理 | 管理具体处理任务，定义客户、项目、数据源、渠道对应的处理流程、执行策略、调度方式、失败重试和启停状态。 |
| 处理流水线 | 后处理配置 | 配置模型输出后的处理逻辑，包括结构化、标签映射、观点归一、关键词清洗、置信度计算、冲突检测、低置信分流等。 |
| 处理流水线 | 处理记录 | 查看每条数据或每个批次的处理链路，展示各节点输入输出、执行状态、耗时、异常原因和最终结果。 |
| 知识中心 | 标签体系 | 管理多层级标签体系，包括标签类型、标签层级、标签编码、标签名称、适用客户/渠道、状态、属性和业务含义。 |
| 知识中心 | 标准观点 | 管理标准化观点和同义表达，用于模型观点归一、结果查询和分析统计，支持新增、编辑、合并、启停和命中样本查看。 |
| 知识中心 | 关键词库 | 管理业务关键词、规则关键词、风险关键词、账号词库等，用于规则匹配、模型辅助、风险识别和新词处理。 |
| 知识中心 | 语料映射 | 管理文本语料、问卷语料与标签、观点、场景、体验代码之间的映射关系，支撑模型训练、规则配置和结果解释。 |
| 知识中心 | 业务场景 | 管理业务分析场景，如质量问题、服务体验、销售线索、舆情风险、产品体验等，用于分类、规则和监控配置。 |
| 知识中心 | 用车场景 | 管理车辆使用场景，如通勤、长途、露营、充电、售后、保养等，支持场景分类、启停、批量移动和关联标签。 |
| 知识中心 | 品牌车系 | 管理车企、品牌、车系、车型基础数据，支持别名、竞品关系、核心标识、状态、国家、能源类型等配置。 |
| 规则中心 | 数据规则 | 管理数据处理规则，包含前置规则和后置规则，用于数据清洗、过滤、去重、字段补全、字段转换、数据校验和结果修正。 |
| 规则中心 | 业务规则 | 管理业务语义规则，如标签修正规则、观点归一规则、场景识别规则、风险判断规则、情感修正规则等。 |
| 规则中心 | 闭环规则 | 管理需要进入业务闭环的事件规则，包括触发条件、责任部门、通知对象、处理动作、优先级和启停状态。 |
| 规则中心 | 监控规则 | 配置质量和异常监控规则，包括数据量异常、字段缺失、标签波动、模型低置信、后处理失败、人工修改率异常等。 |
| 规则中心 | 规则测试 | 提供规则测试能力，支持单条测试、批量测试、规则组测试和规则+模型+后处理链路测试，展示命中结果和差异。 |
| 审核反馈 | 纠错审核 | 处理用户提交的标签、观点、情感、关键词等纠错申请，支持查看原结果、纠错结果、审核通过、修改通过和驳回。 |
| 审核反馈 | AI低置信审核 | 处理模型置信度低、结果冲突、后处理失败、敏感风险等自动分流的待审核数据，人工确认最终结果。 |
| 审核反馈 | 新词处理 | 处理模型或数据中发现的新词、新表达、新对象，支持分配到标签、观点、关键词、业务场景或加入候选池。 |
| 审核反馈 | 未归一观点 | 管理模型未能匹配到标准观点的原始观点，支持归一到已有观点、新建标准观点、合并或忽略。 |
| 审核反馈 | 反馈样本 | 沉淀人工通过、修改、驳回、纠错、新词处理等反馈样本，用于后续评测、规则优化、知识优化和模型改进。 |
| 监控中心 | 数据质量监控 | 监控原始数据和标准化数据质量，包括字段完整率、格式异常、枚举异常、重复率、接入延迟和数据量波动。 |
| 监控中心 | 处理链路监控 | 监控处理流水线各节点执行情况，包括任务量、成功率、失败率、平均耗时、卡点节点和失败原因。 |
| 监控中心 | 标签质量监控 | 监控标签覆盖率、标签命中量、标签波动、低置信标签、人工修改率、标签异常增长或骤降。 |
| 监控中心 | 模型质量监控 | 监控模型调用量、成功率、失败率、平均耗时、低置信占比、人工通过率、人工修改率和异常输出。 |
| 监控中心 | 后处理质量监控 | 监控后处理流程和节点执行质量，包括结构化失败、映射失败、观点归一失败、冲突检测、转人工率和失败原因。 |
| 监控中心 | 告警事件 | 汇总监控规则触发的告警事件，支持查看详情、分派处理人、确认、忽略、关闭和关联异常样本。 |
| 系统管理 | 客户管理 | 管理租户/客户信息，包括客户名称、编码、状态、数据范围、启用模块、默认配置和负责人。 |
| 系统管理 | 项目管理 | 管理客户下的项目，配置项目数据源、渠道、标签体系、处理流程、模型策略、规则策略和权限范围。 |
| 系统管理 | 模型配置 | 管理可用模型及业务使用策略，包括模型名称、类型、供应商、适用任务、版本、默认模型、启停状态和失败兜底。 |
| 系统管理 | 下载管理 | 管理异步导出任务，包括原始数据、结果数据、监控明细、审核记录、规则测试结果等文件的生成、下载和重试。 |
| 系统管理 | 账号管理 | 管理系统用户，支持新增、编辑、禁用、删除账号，绑定角色、部门、客户、项目和数据权限。 |
| 系统管理 | 角色管理 | 管理角色和权限模板，配置菜单权限、按钮权限、数据权限、导出权限和管理范围。 |
| 系统管理 | 权限管理 | 管理菜单、按钮、接口、客户、项目、渠道、品牌、标签等权限资源和授权关系。 |
| 系统管理 | 操作审计 | 记录用户关键操作，包括登录、查询、导出、配置变更、规则发布、审核处理、数据重跑和权限变更。 |
