# VOC标签体系设计文档

## 1. 概述

### 1.1 设计目标
VOC平台的标签体系旨在通过多维度、多层级的标签分类，实现对客户声音的精准分析和深度洞察，支持产品优化、服务改进和营销决策。

### 1.2 设计原则
- **全面性**: 覆盖客户声音的各个维度
- **层次性**: 采用多层级分类，便于精细化分析
- **一致性**: 标签命名和编码规范统一
- **扩展性**: 支持未来业务扩展和新标签添加
- **实用性**: 标签具有明确的业务价值和应用场景

### 2.2 标签层级结构
每类标签都采用4级层级结构：

```
一级标签 (主要分类)
├── 二级标签 (子分类)
│   ├── 三级标签 (具体项目)
│   │   └── 四级标签 (详细描述)
│   └── 三级标签 (具体项目)
│       └── 四级标签 (详细描述)
└── 二级标签 (子分类)
    ├── 三级标签 (具体项目)
    │   └── 四级标签 (详细描述)
    └── 三级标签 (具体项目)
        └── 四级标签 (详细描述)
```

## 3. 详细标签分类

### 3.1 VTR标签 (Vehicle Technology Related)

**标签说明**: 车辆技术相关标签，用于标识客户对车辆技术特性的评价和关注点。

#### 3.1.1 动力系统
- **一级**: 动力
  - **二级**: 发动机
    - **三级**: 动力输出
      - **四级**: 加速性能、最大功率、最大扭矩、燃油经济性
    - **三级**: 发动机噪音
      - **四级**: 怠速噪音、高速噪音、冷启动噪音
  - **二级**: 变速箱
    - **三级**: 换挡平顺性
      - **四级**: 自动挡平顺性、手动挡手感、换挡逻辑
    - **三级**: 变速箱可靠性
      - **四级**: 故障率、耐用性、维护成本

#### 3.1.2 操控系统
- **一级**: 操控
  - **二级**: 驾驶体验
    - **三级**: 方向盘手感
      - **四级**: 转向精准度、方向盘重量、回正性能
    - **三级**: 底盘调校
      - **四级**: 悬挂硬度、过弯稳定性、路感反馈
  - **二级**: 悬挂系统
    - **三级**: 舒适性调校
      - **四级**: 减震效果、过坑表现、高速稳定性

#### 3.1.3 外观设计
- **一级**: 外观
  - **二级**: 车身造型
    - **三级**: 侧面线条
      - **四级**: 腰线设计、轮毂样式、车身比例
    - **三级**: 前脸设计
      - **四级**: 大灯造型、进气格栅、品牌标识
  - **二级**: 外观设计
    - **三级**: 整体风格
      - **四级**: 运动风格、商务风格、家用风格

#### 3.1.4 内饰配置
- **一级**: 内饰
  - **二级**: 内饰设计
    - **三级**: 仪表台设计
      - **四级**: 中控布局、按键设计、材质质感
    - **三级**: 座椅配置
      - **四级**: 座椅材质、座椅调节、座椅加热

### 3.2 COM标签 (Commercialization)

**标签说明**: 商品化属性标签，用于标识客户对车辆商品化特性的评价和需求。

#### 3.2.1 座椅配置
- **一级**: 座椅
  - **二级**: 座椅舒适性
    - **三级**: 座椅材质
      - **四级**: 真皮座椅、织物座椅、混合材质
    - **三级**: 座椅功能
      - **四级**: 电动调节、记忆功能、按摩功能

#### 3.2.2 空调系统
- **一级**: 空调
  - **二级**: 制冷效果
    - **三级**: 制冷速度
      - **四级**: 快速制冷、温度控制、出风均匀性
    - **三级**: 空调噪音
      - **四级**: 风机噪音、压缩机噪音

#### 3.2.3 音响系统
- **一级**: 音响
  - **二级**: 音质效果
    - **三级**: 音响品牌
      - **四级**: 品牌音响、普通音响、音响数量
    - **三级**: 音质表现
      - **四级**: 低音效果、中音清晰度、高音表现

#### 3.2.4 安全配置
- **一级**: 安全
  - **二级**: 主动安全
    - **三级**: 驾驶辅助
      - **四级**: 自适应巡航、车道保持、自动刹车
    - **三级**: 预警系统
      - **四级**: 碰撞预警、盲点监测、疲劳驾驶提醒

### 3.3 ADB标签 (All Domain Business)

**标签说明**: 全领域业务标签，用于标识客户声音中涉及的业务领域和流程。

#### 3.3.1 产品规划
- **一级**: 产品
  - **二级**: 产品定位
    - **三级**: 目标市场
      - **四级**: 年轻用户、家庭用户、商务用户
    - **三级**: 产品策略
      - **四级**: 差异化定位、价格策略、配置策略

#### 3.3.2 市场营销
- **一级**: 营销
  - **二级**: 推广活动
    - **三级**: 广告投放
      - **四级**: 电视广告、网络广告、户外广告
    - **三级**: 促销活动
      - **四级**: 价格优惠、赠品活动、金融政策

#### 3.3.3 售后服务
- **一级**: 服务
  - **二级**: 维修保养
    - **三级**: 服务质量
      - **四级**: 维修质量、服务态度、维修速度
    - **三级**: 服务网络
      - **四级**: 网点覆盖、服务便利性、配件供应

#### 3.3.4 品牌建设
- **一级**: 品牌
  - **二级**: 品牌形象
    - **三级**: 品牌认知
      - **四级**: 品牌知名度、品牌美誉度、品牌忠诚度
    - **三级**: 品牌传播
      - **四级**: 品牌故事、品牌活动、品牌代言

### 3.4 WOM标签 (Word of Mouth)

**标签说明**: 口碑评价指标标签，用于标识客户的口碑传播行为和评价倾向。

#### 3.4.1 推荐意愿
- **一级**: 推荐
  - **二级**: 推荐倾向
    - **三级**: 推荐强度
      - **四级**: 强烈推荐、一般推荐、不推荐
    - **三级**: 推荐对象
      - **四级**: 朋友推荐、家人推荐、同事推荐

#### 3.4.2 满意度评价
- **一级**: 满意度
  - **二级**: 整体满意度
    - **三级**: 满意度等级
      - **四级**: 非常满意、满意、一般、不满意
    - **三级**: 满意度维度
      - **四级**: 产品满意度、服务满意度、价格满意度

#### 3.4.3 品牌认知
- **一级**: 认知
  - **二级**: 品牌了解
    - **三级**: 了解程度
      - **四级**: 非常了解、比较了解、一般了解
    - **三级**: 了解渠道
      - **四级**: 广告了解、口碑了解、体验了解

#### 3.4.4 购买意向
- **一级**: 购买
  - **二级**: 购买意愿
    - **三级**: 购买概率
      - **四级**: 肯定会买、可能会买、不确定、不会买
    - **三级**: 购买时间
      - **四级**: 立即购买、近期购买、远期购买

### 3.5 CX标签 (Customer Experience)

**标签说明**: 客户体验指标标签，用于标识客户在各个接触点的体验感受。

#### 3.5.1 购买体验
- **一级**: 购买
  - **二级**: 购车流程
    - **三级**: 流程便利性
      - **四级**: 手续简化、时间效率、流程透明
    - **三级**: 价格体验
      - **四级**: 价格合理性、议价空间、优惠政策

#### 3.5.2 使用体验
- **一级**: 使用
  - **二级**: 日常使用
    - **三级**: 便利性
      - **四级**: 操作便利、功能实用、空间利用
    - **三级**: 舒适性
      - **四级**: 乘坐舒适、驾驶舒适、环境舒适

#### 3.5.3 服务体验
- **一级**: 服务
  - **二级**: 服务态度
    - **三级**: 服务人员
      - **四级**: 专业程度、服务态度、响应速度
    - **三级**: 服务流程
      - **四级**: 流程顺畅、信息透明、问题解决

#### 3.5.4 售后体验
- **一级**: 售后
  - **二级**: 维修体验
    - **三级**: 维修质量
      - **四级**: 维修效果、维修速度、维修成本
    - **三级**: 保养体验
      - **四级**: 保养便利、保养质量、保养成本

### 3.6 CJ标签 (Customer Journey)

**标签说明**: 全旅程客户标签，用于标识客户在购买和使用全过程中的行为特征。

#### 3.6.1 认知阶段
- **一级**: 认知
  - **二级**: 信息获取
    - **三级**: 获取渠道
      - **四级**: 网络搜索、朋友推荐、广告宣传
    - **三级**: 信息内容
      - **四级**: 产品信息、价格信息、配置信息

#### 3.6.2 考虑阶段
- **一级**: 考虑
  - **二级**: 对比分析
    - **三级**: 对比维度
      - **四级**: 价格对比、配置对比、品牌对比
    - **三级**: 决策因素
      - **四级**: 性价比、品牌口碑、售后服务

#### 3.6.3 购买阶段
- **一级**: 购买
  - **二级**: 购买行为
    - **三级**: 购买方式
      - **四级**: 全款购买、分期购买、置换购买
    - **三级**: 购买地点
      - **四级**: 4S店购买、线上购买、车展购买

#### 3.6.4 使用阶段
- **一级**: 使用
  - **二级**: 使用场景
    - **三级**: 使用频率
      - **四级**: 日常通勤、长途旅行、商务出行
    - **三级**: 使用环境
      - **四级**: 城市道路、高速公路、乡村道路

### 3.7 SL标签 (Sales Lead)

**标签说明**: 销售线索标签，用于标识客户的购买意向和销售机会。

#### 3.7.1 潜在客户
- **一级**: 潜在
  - **二级**: 客户特征
    - **三级**: 人口特征
      - **四级**: 年龄分布、收入水平、教育程度
    - **三级**: 行为特征
      - **四级**: 浏览行为、咨询行为、关注度

#### 3.7.2 意向客户
- **一级**: 意向
  - **二级**: 购买意向
    - **三级**: 意向强度
      - **四级**: 强烈意向、一般意向、弱意向
    - **三级**: 意向产品
      - **四级**: 具体车型、配置偏好、价格区间

#### 3.7.3 成交客户
- **一级**: 成交
  - **二级**: 成交特征
    - **三级**: 成交产品
      - **四级**: 成交车型、成交配置、成交价格
    - **三级**: 成交过程
      - **四级**: 成交周期、成交渠道、成交方式

#### 3.7.4 流失客户
- **一级**: 流失
  - **二级**: 流失原因
    - **三级**: 产品因素
      - **四级**: 价格因素、配置因素、品牌因素
    - **三级**: 服务因素
      - **四级**: 服务态度、服务效率、服务质量

### 3.8 OM标签 (Omni Media)

**标签说明**: 全媒体指标标签，用于标识客户声音在不同媒体渠道的传播效果和影响力。

#### 3.8.1 传播效果
- **一级**: 传播
  - **二级**: 传播范围
    - **三级**: 传播广度
      - **四级**: 覆盖人群、传播速度、传播深度
    - **三级**: 传播质量
      - **四级**: 传播准确性、传播及时性、传播完整性

#### 3.8.2 互动数据
- **一级**: 互动
  - **二级**: 互动行为
    - **三级**: 互动类型
      - **四级**: 点赞、评论、分享、收藏
    - **三级**: 互动质量
      - **四级**: 互动深度、互动频率、互动价值

#### 3.8.3 影响力评估
- **一级**: 影响力
  - **二级**: 影响范围
    - **三级**: 影响人群
      - **四级**: 目标用户、潜在用户、意见领袖
    - **三级**: 影响程度
      - **四级**: 强影响、中等影响、弱影响

#### 3.8.4 舆情监控
- **一级**: 舆情
  - **二级**: 舆情态势
    - **三级**: 舆情方向
      - **四级**: 正面舆情、负面舆情、中性舆情
    - **三级**: 舆情热度
      - **四级**: 高热舆情、中热舆情、低热舆情

## 4. 标签应用场景

### 4.1 产品优化
- **VTR标签**: 识别产品技术问题，指导产品改进
- **COM标签**: 了解用户对商品化属性的需求
- **CX标签**: 优化用户体验，提升用户满意度

### 4.2 营销策略
- **WOM标签**: 制定口碑营销策略，提升品牌影响力
- **SL标签**: 精准识别销售机会，优化营销投入
- **OM标签**: 评估营销效果，优化传播策略

### 4.3 服务改进
- **CX标签**: 识别服务痛点，改进服务流程
- **ADB标签**: 优化业务流程，提升服务质量
- **CJ标签**: 优化客户旅程，提升客户体验

### 4.4 决策支持
- **多标签组合**: 提供多维度的决策支持
- **趋势分析**: 通过标签变化趋势指导战略决策
- **竞品分析**: 通过标签对比分析竞争优势

- **质量监控**: 监控标签标注质量和准确性
- **版本管理**: 管理标签体系的版本变更

### 5.2 标签标准化
- **命名规范**: 统一的标签命名规范
- **编码规范**: 统一的标签编码规范
- **分类规范**: 统一的标签分类规范

### 5.3 标签应用
- **培训指导**: 提供标签应用培训
- **工具支持**: 提供标签应用工具
- **效果评估**: 评估标签应用效果
