## 示例1: 基础产品数据简报查询

### 业务场景
获取指定时间范围内的产品基础数据，包括负面率、正面率、提及量、用户数及环比数据。

### Java调用代码
```java
@Service
public class ProductAnalysisService {
    
    @Autowired
    private ProductAnalysisMapper productAnalysisMapper;
    
    public ProductBriefVo getProductBrief(ProductAnalysisRequest request) {
        // 构建查询参数
        Map<String, Object> params = new HashMap<>();
        params.put("startDate", "2024-01-01");
        params.put("endDate", "2024-01-31");
        params.put("dateUnit", 1);  // 按天统计
        params.put("scaleMagnitude", 31);  // 31天
        params.put("typeR", 1);  // 环比类型
        params.put("typeY", 0);  // 不包含同比
        params.put("brandCodeList", Arrays.asList("AVT"));
        
        return productAnalysisMapper.getProductBrief(params);
    }
}
```

### SQL执行逻辑
```sql
-- 1. 生成时间工具表
WITH common_date_tools AS (
    -- 生成完整的日期序列
    SELECT ic, date_, date_unit, ...
    FROM date_range_calculation
)

-- 2. 关联业务数据
SELECT 
    date_str as date,
    ifnull((negative_c/sum_c) * 100, 0) as negativeRate,
    negative_c as negativeMentions,
    sum_c as totalMentions
FROM common_date_tools ct
LEFT JOIN (
    -- 按日期聚合业务数据
    SELECT 
        data_create_time as date_str,
        count(*) as sum_c,
        sum(sentiment = '负面') as negative_c
    FROM voc_sentiment_annotations_results_v
    WHERE date(data_create_time) BETWEEN '2024-01-01' AND '2024-01-31'
    GROUP BY data_create_time
) c ON ct.date_ = c.date_str
WHERE ic = 0  -- 只取当前期数据
ORDER BY date_str ASC
```

### SQL关键差异
```sql
-- 品牌维度：直接按标签聚合
SELECT
    adb_tag_second as tagName,
    adb_tag_second_code as tagCode,
    CASE 
        WHEN dataType = 'negativeRate' THEN ifnull(negative_c/sum_c * 100, 0)
        WHEN dataType = 'mention' THEN sum_c
    END as value
FROM aggregated_data
WHERE ic = 0

-- 车系维度：需要关联车系数量进行标准化
SELECT 
    adb_tag_second as tagName,
    CASE 
        WHEN dataType = 'negativeRate' THEN ifnull(negative_c/sum_c * 100, 0)
        WHEN dataType = 'mention' THEN sum_c
    END as value
FROM aggregated_data
CROSS JOIN (
    SELECT COUNT(DISTINCT car_series_code) AS car_series_c
    FROM voc_sentiment_annotations_results_v
    WHERE brand_code = "AVT"
) car_series_count
WHERE ic = 0
```

## 示例8: 错误处理和边界情况

### 8.1 数据为空的处理
```java
public ProductBriefVo getProductBriefSafely(ProductAnalysisRequest request) {
    try {
        ProductBriefVo result = productAnalysisMapper.getProductBrief(buildParams(request));
        
        // 处理空结果
        if (result == null) {
            result = new ProductBriefVo();
            result.setNegativeRate(0.0);
            result.setPositiveRate(0.0);
            result.setMentions(0L);
            result.setUsers(0L);
        }
        
        // 处理异常值
        if ("999999".equals(result.getPositiveRateMoM())) {
            result.setPositiveRateMoM("新增");
        }
        
        return result;
    } catch (Exception e) {
        log.error("查询产品简报失败", e);
        return createEmptyResult();
    }
}
```

### 8.2 参数验证
```java
private void validateParams(ProductAnalysisRequest request) {
    if (request.getStartDate() == null || request.getEndDate() == null) {
        throw new IllegalArgumentException("开始日期和结束日期不能为空");
    }
    
    if (request.getDateUnit() == null || request.getDateUnit() < 1 || request.getDateUnit() > 5) {
        throw new IllegalArgumentException("时间粒度必须在1-5之间");
    }
    
    if (request.getBrandCodeList() == null || request.getBrandCodeList().isEmpty()) {
        throw new IllegalArgumentException("品牌代码列表不能为空");
    }
}
```

## 示例9: 性能优化实践

### 9.1 分页查询
```java
public PageResult<SceneTopVo> getFocusSceneTopWithPage(
        ProductAnalysisRequest request, int pageNum, int pageSize) {
    
    // 先查询总数
    Map<String, Object> countParams = buildCommonParams(request);
    Long totalCount = productAnalysisMapper.getFocusSceneCount(countParams);
    
    // 再查询分页数据
    Map<String, Object> params = buildCommonParams(request);
    params.put("offset", (pageNum - 1) * pageSize);
    params.put("limit", pageSize);
    
    List<SceneTopVo> data = productAnalysisMapper.getFocusSceneTopWithPage(params);
    
    return PageResult.<SceneTopVo>builder()
        .data(data)
        .total(totalCount)
        .pageNum(pageNum)
        .pageSize(pageSize)
        .build();
}
```

### 9.2 缓存策略
```java
@Cacheable(value = "productAnalysis", key = "#request.cacheKey()")
public ProductBriefVo getProductBriefCached(ProductAnalysisRequest request) {
    return productAnalysisMapper.getProductBrief(buildParams(request));
}

// 在Request类中添加缓存key生成方法
public String cacheKey() {
    return String.format("brief_%s_%s_%d_%s", 
        startDate, endDate, dateUnit, 
        String.join(",", brandCodeList));
}
```

## 总结

以上示例展示了ProductAnalysisMapper的各种使用场景，从基础查询到复杂分析，从错误处理到性能优化。在实际使用中，建议：

1. **参数验证**：始终验证输入参数的有效性
2. **异常处理**：妥善处理查询异常和空结果
3. **性能监控**：监控查询性能，适时优化
4. **缓存策略**：对频繁查询的数据使用缓存
5. **测试覆盖**：编写充分的单元测试和集成测试
