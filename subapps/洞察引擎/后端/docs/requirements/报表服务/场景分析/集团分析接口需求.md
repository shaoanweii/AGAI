# 集团分析接口需求

- 模块：报表服务 / 场景分析
- 接口分层：Controller / Service / ServiceImpl / Mapper
- 备注：占位文档，后续根据业务补充详细入参、回参与SQL说明。

#### 品牌趋势变化接口
- 数据范围：数据产生时间(data_create_time)范围内业务宽表VocSoundsEntity（voc_sentiment_annotations_results_v）的数据
    - 入参：
        - 公共查询条件（ExtendComQueryModel）
    - 回参：(集合数组)
        - 时间轴
        - 品牌数据（集合数组）
          - 品牌名称
          - 品牌编码
          - 负面率环比
          - 提及量
          - 提及量环比
          - 集团均值
- 说明：
    - 根据入参中的开始/结束时间查询data_create_time范围内的数据，根据时间进行分组，求每个品牌下，每个时间点上各品牌的负面率、提及量、 mentions_mean
    - 如果输入的开始/结束时间超过30天，则时间轴以月为单位进行展示（近一 12个 月的数据），否则以天为单位进行展示


#### 集团车系排行接口
- 数据范围：数据产生时间(data_create_time)范围内业务宽表VocSoundsEntity（voc_sentiment_annotations_results_v）的数据
    - 入参：
        - 公共查询条件（ExtendComQueryModel）
    - 回参：
        - 车系top10（集合数组）
            - 车系图片
            - 车系名称
            - 车系编码
            - 负面率
            - 提及量
            - 提及量趋势数组
            - 负面数趋势数组
        - 品牌top10（集合数组）
            - 品牌图片
            - 品牌名称
            - 品牌编码
            - 负面率
            - 提及量
            - 提及量趋势数组
            - 负面数趋势数组
- 说明：
    - 根据入参中的开始/结束时间查询data_create_time范围内的数据
    - 提及量趋势数组，负面数趋势数组 示例[3,4,4,5,6,7,8,9,10,11,12],有多少天的时间点，就有多少个数据


#### 服务口碑分析接口

    - 入参：

    - 回参：(集合数组)
        - 品牌图片
        - 品牌名称
        - 品牌编码
        - 标签数据（集合数组）
            - 一级标签名称
            - 一级标签code
            - 二级标签名称
            - 二级标签code
            - 提及量
            - 负面率
- 说明：
    - 根据入参中的开始/结束时间查询data_create_time范围内的数据
