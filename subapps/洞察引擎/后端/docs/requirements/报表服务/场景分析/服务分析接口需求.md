# 服务分析接口需求

- 模块：报表服务 / 场景分析
- 接口分层：Controller / Service / ServiceImpl / Mapper
- 备注：占位文档，后续根据业务补充详细入参、回参与SQL说明。

#### 省份排行接口
- 数据范围：数据产生时间(data_create_time)范围内业务宽表VocSoundsEntity（voc_sentiment_annotations_results_v）的adb_tag_first为服务的数据
    - 入参：
        - 公共查询条件（ExtendComQueryModel）
    - 回参：（集合数组）
        - 省份名称
        - 省份编码
        - 负面率
        - 提及量
- 说明：
    - 根据入参中的开始/结束时间查询data_create_time范围内的adb_tag_first为服务的数据，按省份名称进行分组，计算负面率、提及量


#### 经销商评价排行top接口
- 数据范围：数据产生时间(data_create_time)范围内业务宽表VocSoundsEntity（voc_sentiment_annotations_results_v）的adb_tag_first为服务的数据
    - 入参：
        - 公共查询条件（ExtendComQueryModel）
    - 回参：（集合数组）
        - 经销商名称
        - 经销商编码
        - 省份名称
        - 经销商编码
        - 负面率
        - 提及量
- 说明：
    - 根据入参中的开始/结束时间查询data_create_time范围内的adb_tag_first为服务的数据，按经销商名称进行分组top10，计算负面率、提及量
    - 当查询条件中无省份编码时，则取所有省份数据，省份名称字段为空，省份编码字段为空
