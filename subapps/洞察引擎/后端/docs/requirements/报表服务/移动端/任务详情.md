# 重庆长安汽车 VOC Report 报表统计服务

## 服务介绍
重庆长安汽车报表统计服务是VOC Cloud系统的数据分析层，负责客户反馈数据的统计、分析和可视化展示。


## 移动端任务详情接口需求说明

### 任务详情接口

#### 任务完成率接口
- 数据范围：当前用户下report_user_browse_record表中本月的用户浏览记录数据
    - 入参：
        - 无
    - 回参：
        - 任务完成率 (create_time 本月意图为抱怨（sound_intention 声音意图）的数量/100)*100
        - 累计浏览时长 (create_time 本月累计浏览时长，格式：xx分yy秒)
        - 浏览数据
            - 总浏览量
            - 抱怨量
            - 咨询量
            - 建议量
            - 表扬量
- 说明：
    - 数据范围是当前用户本月的浏览记录数据

#### 浏览趋势接口
- 数据范围：当前用户下在report_user_browse_record表中本月的用户浏览记录数据
    - 入参：
        - 无
    - 回参：（数组集合）
        - 时间轴 (yyyy-mm-dd) 从本月开始到当前天
        - 浏览数据
            - 总浏览量
            - 抱怨量
            - 咨询量
            - 建议量
            - 表扬量
- 说明：
    - 数据范围是当前用户本月的浏览记录数据


#### 浏览记录接口
- 数据范围：当前用户下在report_user_browse_record表中本月的用户浏览记录数据
    - 入参：
        - 无
    - 回参：（数组集合）
        - 时间轴 (yyyy-mm-dd) 从本月开始到当前天
        - 原文数据 (com.voc.service.insights.report.api.vo.UserVoiceVo)
          com.voc.service.insights.report.api.vo.UserVoiceVo
- 说明：
    - 数据范围是当前用户本月的浏览记录数据
    - 原文数据留空
