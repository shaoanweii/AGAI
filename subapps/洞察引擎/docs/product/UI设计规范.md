# 数据洞察引擎 UI 设计规范

## 1. 设计原则

数据洞察引擎是企业级 VOC 运营后台，界面应服务于高频查询、配置、审核和分析工作。设计风格应克制、清晰、密集但不拥挤，优先保证信息可扫描、操作可预期、状态可识别。

核心原则：

1. 数据优先：列表、筛选、状态、操作入口必须清晰。
2. 稳定一致：同类页面结构、按钮、表单、反馈方式保持一致。
3. 权限可感知：无权限操作不展示或禁用并说明原因。
4. 风险操作谨慎：删除、启停、审核、退出、导出必须确认。
5. 后台气质：避免营销化大图和装饰性元素，以表格、树、表单、抽屉、弹窗为主。

## 2. 技术基线

- UI 框架：Element Plus。
- 图标：Element Plus Icons、项目 SVG 图标、阿里 iconfont。
- 样式：SCSS，全局样式位于 `前端/src/style`。
- 全局入口：`前端/src/style/base.scss`。
- 设计变量：`前端/src/style/_variables.scss` 与 `root.scss`。

## 3. 设计 Token

### 3.1 品牌色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--brand-primary` | `#1677FF` | 主按钮、激活菜单、链接、重点操作 |
| `--brand-secondary` | `#0B457F` | Logo 文案、品牌强调 |
| `--color-primary` | `#165DFF` | 兼容旧样式主色 |

使用规则：

- 页面主操作使用蓝色实心按钮。
- 菜单选中态使用 `#1677FF` 文本和 `#EAF3FF` 背景。
- 链接、可点击文本使用主色。

## 4. 字体

字体族：

```css
ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
'Helvetica Neue', Arial, 'Noto Sans', sans-serif, 'Apple Color Emoji', 'Segoe UI Emoji',
'Segoe UI Symbol', 'Noto Color Emoji'
```

字号规范：

| 级别 | 字号 | 行高 | 字重 | 场景 |
| --- | --- | --- | --- | --- |
| H1 | 32px | 40px | 600 | 大屏或报表主标题 |
| H2 | 24px | 32px | 600 | 页面主标题，少用 |
| H3 | 20px | 28px | 600 | 模块标题 |
| H4 | 16px | 24px | 600 | Header 页签、表格区标题 |
| Body | 14px | 22px | 400/500 | 表单、表格、正文 |
| Caption | 12px | 20px | 400 | 辅助说明、标签 |

当前系统侧边菜单一级项为 16px/600，Logo 标题为 20px/600。

## 5. 布局规范

### 5.1 应用框架

- 页面高度：`100vh`。
- 左侧菜单：默认 280px；折叠 64px。
- Header：84px。
- 主内容：24px padding，纵向滚动。
- 页面最小宽度：1280px。

### 5.2 页面结构

推荐结构：

1. 顶部 Header：页面标题或业务页签。
2. 查询区：白底卡片，圆角 4px，内边距 16-24px。
3. 操作区：表格上方，左侧标题/统计，右侧按钮。
4. 表格区：白底，表头浅灰。
5. 分页：右下角，距离表格 24px。

### 5.3 间距

- 页面外边距：主内容区统一 24px。
- 卡片内边距：24px。
- 查询项横向间距：16px 或 24px。
- 按钮组间距：8px 或 12px。
- 表格与分页间距：24px。
- Header 页签间距：24px。

项目已提供 `mt-*`、`mr-*`、`mb-*`、`ml-*`、`p-*`、`gap-*` 等 1-500px 工具类。新增样式应优先使用明确的局部类，避免过度堆叠工具类。

## 6. 圆角与阴影

| Token | 值 | 场景 |
| --- | --- | --- |
| `--border-radius-s` | 2px | 小标签、小按钮 |
| `--border-radius-m` | 4px | 默认按钮、查询卡片、表格容器 |
| `--border-radius-l` | 6px | 弹窗内容、模块 |
| `--border-radius-xl` | 8px | 重点卡片、输入圆角变体 |
| `--border-radius-c` | 50% | 头像、圆形图标 |

菜单项当前使用 9px 圆角，属于侧边栏专用样式。后台页面主体卡片应以 4px 为主。

阴影使用应克制，仅用于浮层、下拉、弹窗、悬浮提示。常规页面模块不用重阴影。

## 7. 导航规范

### 7.1 侧边菜单

- Logo 区高度 84px。
- Logo 图片 48px，左边距 16px。
- 菜单区白底，菜单项圆角，选中态浅蓝底。
- 一级菜单图标 24px。
- 菜单文字 16px，字重 600。
- 子菜单文字左缩进 12px。
- 菜单顺序以后端权限返回顺序为准。

### 7.2 Header 页签

部分页面不显示静态标题，而显示业务页签：

- 数据查询：结果数据 / 原始数据。
- 新词发现：文本新词 / 问卷新词。
- 关键词库：规则词库 / 账号词库。
- 语料映射：文本语料 / 问卷语料。
- 品牌车系：车系管理 / 品牌管理 / 车企管理。
- 闭环规则：单点事件 / 批量事件。

页签样式：

- 激活项：主色，字重 600。
- 未激活项：次级文本色。
- 页签间距：24px。
- 点击页签只切换当前页面业务状态，不跳转路由。

## 8. 表格规范

### 8.1 表格视觉

- 表头背景：`#F5F7FA` 或 `#F2F3F5`。
- 表头文字：`#1D2129`，600。
- 表格正文：`#1D2129`，500 或 400。
- Hover 行：Element Plus 浅灰/浅蓝。
- 表格高度可使用自动填充 Hook，确保分页固定在底部。

### 8.2 表格字段顺序

通用顺序：

1. 选择列。
2. 序号或业务 ID。
3. 核心名称/标题。
4. 业务属性字段。
5. 状态。
6. 创建人/更新人。
7. 创建时间/更新时间。
8. 操作列。

### 8.3 操作列

- 常用操作：详情、编辑、复制、启用/禁用、删除、审核。
- 危险操作使用红色文字或危险按钮，并二次确认。
- 操作超过 3 个时使用“更多”下拉。
- 无权限操作不展示；只读场景可展示禁用态并提供 Tooltip。

## 9. 表单规范

### 9.1 查询表单

- 查询区为白底卡片。
- 支持查询、重置。
- 高频条件放首行：关键词、状态、时间、客户、渠道。
- 时间范围统一使用日期范围组件。
- 树形选择使用 Cascader 或 TreeSelect。
- 查询按钮为主按钮，重置为默认按钮。

### 9.2 新增/编辑表单

- 使用弹窗或抽屉。
- 标题格式：新增 + 对象名、编辑 + 对象名。
- 底部按钮：取消、确定。
- 必填项使用 Element Plus 表单校验。
- 编码、名称、层级、状态、适用范围为配置类对象常见字段。

### 9.3 校验

- 必填：名称、编码、客户、状态、归属分类。
- 唯一：编码、同分类名称、角色名、账号标识。
- 格式：手机号、邮箱、URL、数字范围。
- 业务：启用前规则完整、删除前无子级或无引用。

## 10. 弹窗、抽屉与确认

### 10.1 弹窗

适合短表单、详情、分配操作。宽度建议：

- 小弹窗：480px。
- 中弹窗：640px。
- 大弹窗：800-960px。

### 10.2 抽屉

适合长表单、规则配置、详情审阅。当前全局抽屉样式：

- Header 高度 48px。
- Header padding：0 24px。
- Body padding：12px 16px。

### 10.3 二次确认

必须确认的操作：

- 删除。
- 批量删除。
- 启用/禁用。
- 审核通过/驳回。
- 退出登录。
- 重新下载。
- 导出敏感数据。

确认文案应包含对象名和后果，例如：“确定禁用该规则吗？禁用后将不再参与命中。”

## 11. 状态规范

### 11.1 通用状态

- 启用：绿色。
- 禁用：灰色。
- 待审核：警告色。
- 通过：绿色。
- 驳回：红色。
- 处理中：蓝色。
- 失败：红色。

### 11.2 下载任务状态

- 排队中：信息色。
- 生成中：信息色。
- 已完成：成功色。
- 失败：错误色，可重试。
- 已过期：灰色，不可下载。

### 11.3 规则状态

- 草稿：灰色。
- 校验中：信息色。
- 校验失败：错误色。
- 已启用：成功色。
- 已禁用：灰色。

## 12. 图标规范

- 优先使用 Element Plus Icons。
- 菜单使用项目 SVG：`menus-database-2-fill`、`menus-instance-fill`、`menus-edit-circle-fill`、`menus-ruler-fill`、`menus-settings-6-fill`。
- 操作按钮中可使用编辑、删除、下载、搜索、文件、文件夹等图标。
- 图标默认 16px 或 24px，菜单图标 24px。
- 图标颜色跟随文本状态，不单独制造新颜色。

## 13. 空态、加载与错误

### 13.1 空态

- 表格无数据时显示 Element Plus empty 或项目空态图。
- 空态文案使用“暂无数据”。
- 有创建权限时可提供“新增”按钮。

### 13.2 加载

- 列表查询、保存、删除、导出均应有 loading。
- 长任务不阻塞页面，生成下载任务后提示到下载管理查看。

### 13.3 错误

- 接口错误用 `ElMessage.error`。
- 表单错误在字段下方展示。
- 权限错误跳转 `/403` 或展示无权限提示。
- 无菜单权限进入 `/redirect`。

## 14. 图表规范

项目图表色板：

`#1677FF`、`#0AADFF`、`#28C7C7`、`#14CA64`、`#FACE0C`、`#FAB007`、`#FE7840`、`#FF5959`、`#9772FB`、`#6675FF`、`#7298D0`

使用规则：

- 趋势图：蓝色为主，异常/负面使用红色。
- 排名图：默认蓝色，Top/风险项可用橙红强调。
- 饼图/环图：最多 7 类，超过合并“其他”。
- 图表必须有标题、单位、空态、loading。
- 报表图表应支持按时间、品牌、车系、渠道筛选。

## 15. 响应式规范

当前系统面向桌面后台，`body` 最小宽度 1280px。优先保证桌面体验。

要求：

- 1280px 下不横向挤压核心操作。
- 表格字段过多时允许横向滚动。
- 弹窗宽度不得超过视口 90%。
- 菜单折叠后内容区应自适应。

## 16. 页面模板

### 16.1 列表页模板

1. Header 标题/页签。
2. 查询卡片。
3. 表格操作栏。
4. 表格。
5. 分页。
6. 新增/编辑弹窗。
7. 删除/启停确认。

适用页面：账号管理、角色管理、属性标签、用车场景、品牌车系、下载管理。

### 16.2 树 + 列表模板

1. 左侧分类树。
2. 右侧查询区。
3. 右侧列表。
4. 分类新增/编辑/删除。
5. 内容新增/编辑/移动/启停。

适用页面：用车场景、体验代码、标签目录、批量规则分类。

### 16.3 规则配置模板

1. 基础信息。
2. 适用范围。
3. 触发条件。
4. 指标条件或处理动作。
5. 测试/校验。
6. 保存草稿/启用。

适用页面：闭环规则、批量事件、清洗规则。

## 17. 文案规范

- 操作按钮：新增、编辑、删除、复制、启用、禁用、导出、查询、重置、审核、通过、驳回。
- 成功提示：`保存成功`、`删除成功`、`操作成功`、`已退出登录`。
- 失败提示：优先展示后端返回 message。
- 确认标题：`提示`。
- 删除确认：`确定删除该记录吗？`。
- 退出确认：`确定要退出登录吗？`。
