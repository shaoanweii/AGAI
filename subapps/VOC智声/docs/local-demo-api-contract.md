# VOC智声本地 API 契约

## 基础协议

- 基础路径：`/api`
- JSON 响应保持现有 `BaseResponse<T>` 结构。
- 文件上传使用 `multipart/form-data`。
- 导出返回可下载文件流。
- AI 仿真使用 `text/event-stream`。

## 本地控制接口

| 方法 | 路径 | 用途 | 持久化 |
| --- | --- | --- | --- |
| GET | `/api/local/health` | 检查服务、数据仓库和文件库 | 否 |
| GET | `/api/local/runtime` | 返回版本、PC/H5 地址和演示令牌 | 否 |
| POST | `/api/local/session/enter` | 签发演示管理员会话 | 否 |
| POST | `/api/local/admin/reset` | 恢复合成数据基线 | 是 |

## 业务兼容策略

| 类型 | 行为 | 验收标准 |
| --- | --- | --- |
| 查询与分页 | 从同一 JSON 数据仓库筛选并分页 | 图表、列表和详情数据一致 |
| 新增与编辑 | 写入对应集合并刷新更新时间 | 刷新页面后仍存在 |
| 删除与状态流转 | 更新或删除对应实体并记录操作 | PC/H5 显示一致 |
| 上传 | 校验文件名、类型和大小并保存元数据 | 返回可预览结果 |
| 导出 | 按当前数据生成 CSV 下载 | 文件可正常打开 |
| AI 分析 | 根据请求条件输出分段 SSE 文本 | 不访问外部模型 |

完整源码调用路径由 `local-demo/server.mjs` 的兼容路由统一接管；未匹配的 `/api` 请求也返回明确的本地响应，不转发外网。
