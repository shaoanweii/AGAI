# VOC智声离线演示运行手册

## 环境要求

- Node.js 22 或兼容版本
- npm 10 或兼容版本
- Windows、macOS 或 Linux 浏览器环境
- H5 真机演示时，手机与电脑连接同一局域网

## 开发运行

1. 执行 `npm install` 安装依赖。
2. 执行 `npm run dev` 同时启动本地 API 与 Vite。
3. 浏览器访问 `http://127.0.0.1:5173/#/login`。
4. 点击“一键进入 VOC智声”。
5. 在顶部“演示工具”中查看 H5 二维码、复制地址或复位数据。

本地 API 默认监听 `4174`，前端默认监听 `5173`。

## 数据与复位

- 开发模式数据目录：`local-demo/.data`。
- 正常退出不会清空数据。
- “恢复演示数据”会重建固定合成基线，并按当前日期重排数据时间。

## 离线与故障恢复

- 本地模式不依赖远程认证、企业 SDK、外部模型或生产接口。
- H5 无法扫码时，使用“演示工具”中的桌面 H5 预览。
- 端口冲突时，先停止占用进程，再重新执行 `npm run dev`。
- 数据异常时执行 `POST /api/local/admin/reset` 或使用界面复位按钮。

## 发布

- 本地构建：`npm run build:local`
- 清洁门禁：`npm run verify:neutral`
- 生产静态资源输出目录：`dist`
